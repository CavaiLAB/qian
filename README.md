## 定位

Qian 0.2.1 提供设计令牌、React 组件、远程页面加载，以及由 Schema 驱动的表单和列表。

已有项目可以按需使用冻结版本。

- **当组件库用。** 装几个包，在自己的 React 项目里用设计令牌和组件。
- **当应用框架用。** 用外壳组件搭宿主页面，业务页面作为远程模块按需加载，表单和列表由 Schema 渲染。Kun 仓库中的现有应用外壳采用这种方式。[框架架构第 3 节](docs/architecture.md#3-应用外壳)

## 设计原则

1. **分层，下层不引用上层。** 包之间允许的依赖写在一张矩阵里，违反即检查失败，不接受「先引用、以后再改」。
2. **界面由数据描述。** 表单与列表由 Schema 渲染。智能体要改界面，改的是 Schema，不是前端代码。
3. **外壳也是一棵插件树。** 前端有一个与后端同语义的运行时，页面、菜单、控件都是带范围的注册，可以按租户遮蔽。
4. **浏览器里不放令牌。** 会话由网关持有，前端只带会话 Cookie。
5. **可访问性与性能有预算。** 可访问性检查不过、首屏脚本超出预算，都不能合入。
6. **组件不写死文案。** 面向用户的文字由宿主经国际化传入。
